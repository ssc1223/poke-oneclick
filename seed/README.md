# 波奇波奇 博愛店（電小二 cashier.tw）一鍵點餐書籤

## 檔案
- `bookmarklet-save.txt`：書籤①「存餐點」（開始記錄，之後每按一次「加入購物車」就記住那一份，存在這台手機 Chrome 的 localStorage `cashierOneClick.v1`）
- `bookmarklet-restore.txt`：書籤②「一鍵點餐」（依記錄自動點品項、選項並加入購物車）
- `bookmarklet-restore-fixed.txt`：備用，餐點寫死在程式裡（改 `my-order.config.js` 後執行 `python3 build.py` 重新產生）
- `src/`：原始碼；`*.full.js`：組合後可讀版本；`menu-summary.txt`：菜單、選項、加料整理
- 書籤只會按「加入購物車」，**絕對不會按「前往結帳」或付款**。

## 在 Android Chrome 新增書籤小工具
1. 在電腦或手機打開 `bookmarklet-save.txt`，把整段內容（從 `javascript:` 開頭）全部複製。
2. 手機 Chrome 隨便開一個網頁 → 右上角「⋮」→ 點「☆」加入書籤。
3. 「⋮」→「書籤」→ 找到剛加的書籤，長按 →「編輯」。
4. 名稱改成 `存餐點`；網址整個刪掉，貼上剛剛複製的內容 → 返回儲存。
5. 用同樣方法再建一個，名稱 `一鍵點餐`，網址貼 `bookmarklet-restore.txt` 的內容。

## 使用方式
- 要用 **Chrome** 開點餐網址（不要用 LINE 內建瀏覽器，書籤在那裡不能用）。LINE 裡可以點右上角「⋮」→「用預設瀏覽器開啟」。
- 第一次：開點餐頁 → 點網址列，輸入 `存餐點` → 點下面出現的那個書籤（有星號圖示的那一項）→ 按「確定」→ 照平常選好每一份，按「加入購物車」，畫面上方會跳出「已記住第 N 份」。
- 之後：開點餐頁 → 網址列打 `一鍵點餐` → 點那個書籤 → 等幾秒，會自動把餐點加進購物車，再自己檢查購物車然後結帳。
- 網址每次不一樣也沒關係，記錄是存在這個網站（shop.cashier.tw）的手機瀏覽器裡。
- 如果店家改了菜單名稱或某項賣完，提示框會顯示哪一項沒選到或失敗。
